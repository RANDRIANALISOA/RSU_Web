# ⚠️ VERSIONS ÉPINGLÉES, ET C'EST VITAL — NE PAS FAIRE « pip install -U »

# Le processeur de ce serveur est un « Common KVM processor » qui n'expose PAS
# le jeu d'instructions x86-64-v2 : ni sse4_1, ni sse4_2, ni ssse3, ni popcnt
# (vérifié dans /proc/cpuinfo le 2026-09-28).
#
# NumPy >= 2 est compilé avec ce niveau EN BASE et refuse de démarrer :
#
#     NumPy was built with baseline optimizations (X86_V2)
#     but your machine doesn't support (X86_V2)
#
# Ce n'est pas un avertissement, c'est une erreur à l'IMPORT — et rien dans le
# message ne fait penser au processeur, donc le diagnostic coûte cher.
#
# Aujourd'hui « pip install numpy » installerait la 2.4.x : sans l'épinglage
# ci-dessous, tout ce qui dépend de numpy tombe en panne d'un seul coup.
#
# numpy 1.26 fonctionne ; pandas 2.2 est la DERNIÈRE série compatible avec elle,
# et pyreadstat dépend de pandas — la cascade doit rester cohérente.
